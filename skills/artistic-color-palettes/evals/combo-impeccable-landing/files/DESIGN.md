# Design System: Kettle & Crumb

## Overview

**Creative North Star:** "The miller's table"

Brief: a single-scroll landing page whose job is to get a first-time visitor to start a box.
Mode: Persuade. The visitor decides and acts, so colour may carry the voice and own whole regions
of the page. Colour strategy is open; the owner has asked for colours from Sanzo Wada's book and
has pinned a plate in chat.

Layout and type belong to the design skill: a long editorial scroll, a big first-screen statement,
mills before price, one Start a box button repeated three times. Nothing else competes with it.
