## Painting JSON note

The Download JSON button has no URL: the page embeds the export in an inline `<script type="application/json" data-payload="json">` and builds a Blob client side. Each `paintings/<slug>.json` holds that payload verbatim under `export_verbatim` (hex list only) plus `swatches_from_page` (role and coverage parsed from the page HTML).
